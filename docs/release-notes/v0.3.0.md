# v0.3.0 — 3-axis gizmo for precise move & rotate

## ✨ New features

**Gizmo manipulator**
* Select a file in the tree and a gizmo appears at its center: drag the X/Y/Z arrows to move exactly along one axis, or the rotation rings to spin it by any angle — from any viewing angle.
* Selecting another file moves the gizmo to it.

## ⚠️ Known limitation

* The gizmo can be hidden inside solid parts. (Fixed in v0.3.1 — the gizmo now always stays on top.)
