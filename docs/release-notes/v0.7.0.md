# v0.7.0 — Menu bar & customizable quick toolbar

## ✨ New features

**Menu bar**
* Every feature is now in a menu, grouped by File / View / Measure / Transform / Tools — no more hunting through one long row of buttons.

**Quick toolbar you can customize**
* The toolbar now holds only the buttons you use most. Pick which ones under **Quick Bar → Customize**; your choice is remembered next time.

**Tidier section controls**
* The section axis/position bar only appears while section view is on, so it no longer takes up space.

**About dialog**
* **Help → About** shows the version and a plain-language history of what each release brought.

Source only — no prebuilt binaries were published for this version. For a ready-to-run build, grab the [latest release](https://github.com/ETWen/STPViewer/releases/latest).
