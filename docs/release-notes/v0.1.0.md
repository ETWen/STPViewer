# v0.1.0 — First release: STEP viewer with measurement & assembly checks

## ✨ New features

**Open your CAD files**
* Import STEP, STL and DXF — several files at once. STEP assemblies show up as a tree where you can hide/show, recolor or zoom to any part.

**Measure**
* Point, distance, edge length, face, circle (radius/diameter), angle and face-to-face distance. Values come from the exact CAD geometry wherever it's available.

**Check how parts fit**
* Two-point align (move), three-point align (rotate + move), rotate 90° about an axis, and an interference check that reports overlaps or the minimum gap between parts.

**More tools**
* Section view, mm ⇄ inch switch, export measurements to CSV, and save a high-resolution screenshot.
