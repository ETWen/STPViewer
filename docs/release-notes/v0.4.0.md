# v0.4.0 — Faster and more stable

## ✨ Improvements

**Section slider stays responsive on big files**
* Dragging the section slider on large assemblies no longer freezes the screen — the cut is computed in the background and shown as soon as it's ready.

**Faster placement after moving parts**
* After dragging or using the gizmo, the part settles into its new position much faster. The interference check's gap calculation is faster too.

## 🐛 Bug fixes

**Errors no longer close the app**
* If something goes wrong, you now get a message and the app keeps running instead of shutting down. Details are logged to `%LOCALAPPDATA%\STPViewer\error.log`.
* Import, rotate and interference buttons are disabled while a long task is running, so they can't be triggered twice by accident.

## 📦 Downloads

Source only — no prebuilt binaries were published for this version. For a ready-to-run build, grab the [latest release](https://github.com/ETWen/STPViewer/releases/latest).
