# v0.2.0 — Drag parts into place

## ✨ New features

**Drag mode**
* Press and hold a part with the left mouse button and drag it where you want; release to drop it. Smooth even on very large assemblies, and measurement accuracy is unaffected.
* Right-drag rotate, wheel zoom and Shift+drag pan still work as before.
