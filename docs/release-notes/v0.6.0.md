# v0.6.0 — Export to STL

## ✨ New features

**STL export with a settings dialog**
* Save the parts on screen — including any alignment or rotation you applied — as an STL mesh for 3D printing or other software.
* Before exporting you choose: one merged file or one file per input, Binary or ASCII, mm / inch / custom scale, and mesh quality (current or fine).
* The dialog shows the triangle count and estimated file size live, so you know what you'll get before you hit export.
